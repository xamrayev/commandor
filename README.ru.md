# Commandor

[English](README.md) · **Русский** · [O‘zbekcha](README.uz.md)

**Кроссплатформенный двухпанельный файловый менеджер на Rust.**

> **Статус: ранняя разработка (v0.1.0, ноябрь 2026).** Пока работает только просмотр. Копирования, перемещения, переименования и удаления ещё нет. Также пока нет просмотрщика, редактора, поддержки Office, терминала, поискового индекса и локального ИИ. Приложение запускалось только на **macOS arm64**. CI для Windows и Linux написан, но ещё не запускался.

## Что уже работает

- Две независимые панели с реальным содержимым папок. В каждой панели есть ввод пути, домой/вверх/обновить, история назад/вперёд, фильтр по имени и скрытые файлы.
- **Вкладки в каждой панели.** У каждой вкладки своё место, история, выделение и позиция прокрутки.
- **Список томов.** Диски показаны чипами над путём. F1 открывает список для левой панели, F2 — для правой.
- **Палитра команд.** Cmd/Ctrl+Shift+P показывает все команды панели и закладки, с поиском.
- **Закладки** через ★ или Cmd/Ctrl+D. Хранятся только в текущем сеансе.
- Сортировка по имени, размеру и дате; множественное выделение с числом и общим размером выбранного.
- Системный диалог выбора папки; тёмная и светлая темы, которые следуют системе.
- Языки интерфейса: узбекский (основной), русский, английский (Fluent).

### Клавиатура

| Клавиша | Действие |
|---|---|
| Tab | Сменить активную панель |
| ↑ ↓ · PageUp PageDown · Home End | Перемещение курсора |
| Enter · Backspace | Открыть папку · вверх |
| Alt+← / Alt+→ | Назад / вперёд |
| Space / Insert | Выделить и перейти ниже |
| Cmd/Ctrl+T · Cmd/Ctrl+W · Ctrl+Tab | Новая вкладка · закрыть · следующая |
| Cmd/Ctrl+Shift+P | Палитра команд |
| Cmd/Ctrl+D | Добавить закладку |
| Cmd/Ctrl+A · Cmd/Ctrl+Shift+A | Выделить всё · снять выделение |
| Cmd/Ctrl+1 / 2 / 3 | Сортировка по имени / размеру / дате |
| F1 / F2 | Тома для левой / правой панели |

## Сборка и запуск

Нужен стабильный Rust (`rustup`). Проект объявляет MSRV 1.92, но проверен только на 1.94.1.

```sh
cargo run -p commandor-app                     # GUI
cargo run -p commandor-app -- --smoke          # открывается, ждёт обе панели и закрывается
cargo test --workspace                         # модульные тесты и тесты worker-процесса
cargo clippy --workspace --all-targets -- -D warnings
cargo xtask check-boundaries                   # проверка направления зависимостей crate'ов
```

## Архитектура кратко

- **Rust + `egui`/`eframe`.** Приложение — один нативный бинарник.
- **Граница безопасности.** Crate `commandor-ui` не может обращаться к файловой системе, процессам и сети. Это обеспечивают правила Clippy и `#![forbid]`. UI общается только с брокером через `AppHandle`, а брокер проверяет каждую команду.
- **Изолированный worker.** Парсеры недоверенного содержимого, например PDF и OOXML, работают в отдельном процессе `commandor --worker`. Если worker падает, UI продолжает работать.
- **Crate'ы:** [`crates/`](crates/)

  | Crate | Назначение |
  |---|---|
  | `commandor-core` | Типы и протокол |
  | `commandor-broker` | Фасад для UI |
  | `commandor-fs` | Листинг и тома |
  | `commandor-ui` | Интерфейс на egui |
  | `commandor-app` | Бинарник |
  | `commandor-ipc` | Протокол worker'а |
  | `commandor-i18n` | Переводы |

  Переводы лежат в [`resources/i18n/`](resources/i18n/), проверки репозитория — в [`xtask/`](xtask/).

### В планах

- Файловые операции с очередью задач, окном конфликтов и корзиной.
- Текстовый редактор (`ropey` + `syntect`).
- Нативный просмотр Markdown и PDF через PDFium.
- Просмотр и редактирование Office через headless LibreOffice. Встроенное редактирование Office пока под вопросом, поэтому не обещается.
- Полнотекстовый поиск на SQLite FTS5.
- Необязательный локальный ИИ (Ollama или `llama-server`), который только *предлагает* план; ничего не выполняется без подтверждения пользователя.
